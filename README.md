# Tiny d10

The free, tiny tabletop roleplaying game system — simple to learn, quick to play, and easy to adapt to any genre imaginable.

This repository holds the source content for the [Tiny d10](https://x.com/td10rpg) website (previously published via Obsidian Publish, now being rebuilt as a static site hosted on GitHub Pages).

## Contents

- **`Home.md`, `About.md`, `Downloads.md`, `Resources.md`** — the main site pages.
- **`Core.md`** — the Tiny d10 core rule system.
- **`Secret/`** — the *Index of Secrets*: supplementary content for Friends of the System (extra classes, GM guidance, optional rules, and the Land of Glacia setting).
- **`Files/`** — PDFs, images, and templates (character sheets, zines, con kit, artwork, etc.).
- **`publish.css`** — the stylesheet from the original Obsidian Publish site.

Notes are written in [Obsidian](https://obsidian.md) Markdown and use `[[wikilinks]]`, `![[embeds]]`, and `permalink` frontmatter.
